# Code of Conduct

## Our Pledge
We as contributors and maintainers pledge to make participation in this project a harassment-free experience for everyone.

## Our Standards
Examples of behavior that contributes to a positive environment:
- Being respectful in communication and code review.
- Accepting constructive feedback.
- Focusing on what is best for the project and users.

Examples of unacceptable behavior:
- Harassment, insulting or derogatory comments.
- Trolling, personal attacks, or public/private harassment.
- Publishing private information without explicit permission.

## Enforcement Responsibilities
Project maintainers are responsible for clarifying and enforcing these standards and may remove, edit, or reject comments, commits, issues, and PRs that violate this Code of Conduct.

## Scope
This Code of Conduct applies within project spaces and in public spaces when an individual is representing the project.

## Reporting
Report abusive or unacceptable behavior through private contact with the maintainer. Reports will be reviewed and addressed as promptly as possible.
